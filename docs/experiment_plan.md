# IDEA015 实验计划

目标是检验单棵分类树的混合型反事实查询能否在保持最小代价的同时减少重复计算，并找出时间收益消失的条件。以分类器预测为目标，反事实仅表示数据记录在模型中的变化。原始投影相对最近邻的成本降幅是历史诊断，不用于论证新方法。

| 阶段 | 问题与设计 | 输出与决策 |
|---|---|---|
| 1. 历史复现 | 两个固定种子和两种树深，重复调用三次，核查成本、有效率和延迟 | 保留历史值，隔离与候选筛选无关的结果 |
| 2. 正确性验证 | 在小规模混合离散空间穷举所有记录，核查阈值两侧、双动作限制、并列最优和不可行查询。所有主实验以完整叶枚举核对代价和可行性 | 出现一次可行性矛盾或超过绝对误差 1e-9 即停止扩大并修复 |
| 3. 主实验 | 使用事先锁定的本地 OpenML 二分类任务清单，至少 35 个任务，种子 7、13、19、29、37，每个划分分层抽取约 70/30 训练和测试，随机抽取至多 24 个预测负例，比较 CART 与极随机单树。相同划分内方法共享输入、查询和成本 | 保存逐查询记录、划分索引、来源 SHA-256、任务元数据与模型信息。按任务汇总并在任务层做配对估计 |
| 4. 时间与消融 | 比较稠密单次枚举、稠密批处理、条件复用枚举、标量枚举、最近邻、训练叶代表、按路径启发式、通用优先队列搜索及随机筛选。消融筛选、排序和条件复用。预先设定筛选比例 1/8、1/4、1/2、3/4，深度 3、6、9、12，输入维度 8、32、128、256。树训练、索引构建、在线搜索分别计时 | 以条件计算量和在线延迟为两个独立结果。只有主要受益层的配对中位数速度提升至少 20%、95% 区间下界大于 0、且同精度单次枚举全部匹配时，才写成在线加速。单独报告批量对照 |
| 5. 限制、稳定性与案例 | 用矩形选择的四档冻结率、单调方向和不同类别代价测试可行性。在冻结的查询上用同类模型重训及训练数据扰动衡量标签保持率。抽取受益、无收益和不可行案例 | 统计覆盖率、条件成本、训练支持距离、稀疏性、保持率和 P50/P95 延迟，展示失败模式 |
| 6. 初稿与整改 | 依据实验写 LaTeX 初稿并编译，以 papercheck 输出整改项。根据初审优先进行独立求解器核对、域或批量证据补充、修文和复审 | 保存初审和最新整改记录、源文件、PDF 与论文可追溯图表 |

二分类任务按导入值排序后把第二个标签作为目标类。公共任务中的人类属性使用通用模拟限制来测试算法，每条记录的变化不解释为干预。明确的整数和离散压力测试独立于通用基准主协议。计时仅在 CPU 上运行，单线程，方法顺序按种子确定并打乱。后续新增实验标注为补充性检验。
