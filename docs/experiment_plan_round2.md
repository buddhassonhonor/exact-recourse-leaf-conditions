# IDEA015 审后扩展实验

| 阶段 | 固定设计 | 度量 |
|---|---|---|
| 几何与公开算法 | 同树、同字段、同动作约束，比较共享枚举、稠密枚举、按 CF-Maps 论文复现的几何查询、可运行的 OCEAN 官方后端和随机启发式。覆盖五个主种子及不同类别构成 | 覆盖、条件代价、有效预测、索引时间、在线延迟与内存 |
| 外部时间验证 | Bank Marketing、Electricity 和外部 UCI Bike Sharing。五个时间起点分早期训练、校准、更新、测试。四档深度训练内选择 | 无约束、语义可行域最小成本、含训练内重训投票限制三者的覆盖率、保持率、成本和失败原因 |
| 筛选开销诊断 | 对共用同一条件字典的本地编译循环，在相同索引、输入和动作下比较整表累加和原地前缀筛选。保留 SciPy 共享枚举作为原实现控制 | 区分一次性编译和求解时间。报告筛选减少的累加次数，以及同为编译后端时筛选是否能降低时延 |
| 写作和审查 | 保存代码、数据源哈希、划分和逐查询数据，按实测更新论文 | 编译、版面和引用核验，更新 papercheck 与整改清单 |

语义动作规则来自字段定义。Electricity 允许在历史范围内调整调度交换量。Bank Marketing 允许已知电话渠道和少量追加联系次数。Bike Sharing 允许同日前后移动两小时并固定气象和日期背景。研究估计声明的模型输入规则及标签保持率。

Bank Marketing 的初始时间实验显示测试平衡准确率接近 0.5。对应的补充诊断固定相同时间窗口，使用训练样本类别频率的反比权重，并限制双方比较在两种模型均预测为负的同一批记录上。

编译筛选实验完成后，在同一混合基准、相同条件与同一 Numba 后端复测体积区域索引。记录独立的 JIT 冷启动时间和两种方法的热查询延迟，以核对 Python 实现差异对几何对照结论的影响。

同后端几何对照另做桶大小敏感性诊断。固定候选为 2、4、8、16。每棵树从训练预测负样本抽取至多 32 条校准查询，以九次批量计时的中位数选择桶大小，再在冻结的测试查询上与共享枚举和固定桶比较。
