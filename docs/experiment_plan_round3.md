# 第三轮审查后的实验计划

保留首轮主基准、第二轮几何及时间结果。以第三轮整改清单确定新增实验范围。

| 实验 | 预先固定的设计 | 输出和决策 |
|---|---|---|
| 公开求解器深度对照 | 12 个含数值及类别字段的 OpenML 任务，五个原种子，单棵 CART 深度上限 6、10、14。每个数据划分复用三个深度都预测为负的至多八条事实记录。三档动作域为自由、冻结一半和冻结四分之三，后两档另设方向。对比共享枚举、体积索引、OCEAN 官方 MIP 与 CP、DiCE Random、NICE 的邻例贪心方法 | 报告代价匹配、独立复核、不可行区分、时限、资源限制和冷／热端时延。外部失败计入总分母。不同求解器选项用于稳健性诊断，按方法家族计数 |
| 独立进程峰值内存 | German Credit、Bank Marketing、Nomao、Adult 四项覆盖窄、中和宽编码。两个深度 6、14 和两个种子。每种方法在新进程运行，每个模型执行 1、32、128 查询，记录解释器和模型准备后的基线工作集、索引构建阶段和查询阶段的操作系统峰值工作集 | 统计绝对峰值、超出准备阶段峰值的增量，以及单独的初始化时间。按不同体量和批长汇报。系统峰值与统计采样值分开解释 |
| 更长时间及跨城市外部验证 | Electricity、Bank Marketing、Capital Bikeshare 和新的 Seoul Bike Sharing。早期截止点为有序日期／行数的 35% 与 43%，接着 6% 校准。其后间隔 5%、15%、25%、35%，在不重叠的 7% 未来窗测试，并独立拟合更新模型。固定原先字段可编辑规则，Seoul 仅在运营时段内允许同日前后两小时 | 报告早期和更新树的平衡准确率、可行返回、条件保持率、共同覆盖和每百查询可用数。比较固定四票与使用早期校准区选票阈值的策略。比较不把存在重叠训练窗的记录视为独立试验 |
| 论文与复审 | 保存代码快照、源数据哈希、独立进程记录、完整失败分类和期刊预排版 | 根据结果改写摘要、结果、局限和复审清单。市场或交通输入变动不解释为真实干预效应 |

公开的 CF-Maps 论文用于几何复现。基准中的公开包结合实际软件语义与同一外部代价、动作可行域和树预测进行复核。

预试验中，宽特征任务触发了 Gurobi 限规模许可。保留这些运行失败。逐叶 HiGHS 建模在深树上出现过长的端到端时间，保留其部分运行，完整深度矩阵改用不依赖叶投影字典的单位流 HiGHS 模型。每个分支只编码一次，连续流变量传递路径质量，字段选择保持二元。完整矩阵为 HiGHS 设置两秒求解时限，OCEAN 保持三秒。

对 HiGHS 声称不可行但枚举可行、或实际成本高于枚举超过 1e-5 的记录，优先选代价偏差最大的最多 16 个完整基准案例。另保留已观察到的预试验差异。检查低代价向量是否严格满足已构造矩阵，用五秒限时复跑开／关预求解。此诊断不替换原始全量基准结果。

独立进程的内存阶段使用一秒 OCEAN 查询限时与 240 秒进程限时，每个完成的批量阶段立即记录。进程整体限时不丢弃先前阶段的工作集。完整深度对照的时限保持不变。
